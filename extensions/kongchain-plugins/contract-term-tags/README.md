# 合同条款标记工具

统计一段合同/单据文本中各关键词的命中次数并给出首次出现位置片段；纯函数实现，无第三方依赖，不读写文件、不访问网络。

- 包名：`@kongchain-plugin/contract-term-tags`
- 插件名：`contract-term-tags`，工具名：`contract_term_tags`
- 入口：`src/index.js`，纯逻辑：`src/check.js`
- 版本：`0.1.0`

## 工具

`contract_term_tags({ text: string, keywords?: string[] })` 返回：

| 字段 | 含义 |
| --- | --- |
| `textLength` | 文本的 Unicode 码点个数（一个 emoji 计 1，不按 UTF-16 代理对计 2） |
| `totalHits` | 全部关键词命中次数之和（重复出现的关键词按每个条目分别累加） |
| `keywords` | 每个关键词一条：`{ keyword, count, firstIndex, snippet }`，顺序与传入顺序一致 |

单条关键词结果：

| 字段 | 含义 |
| --- | --- |
| `keyword` | 调用方传入的关键词原文（不做大小写或空白归一） |
| `count` | 命中次数（不重叠计数：`aa` 在 `aaaa` 中命中 2 次，`aaa` 在 `aaaa` 中命中 1 次） |
| `firstIndex` | 首次命中的起始位置，按码点计，0 起；未命中为 `-1` |
| `snippet` | 首次命中片段：命中前后各取最多 12 / 18 个码点，连续空白折叠为单个空格，被窗口截断处加 `…`；未命中为 `""` |

### 参数 `keywords`

- 可选，字符串数组，至少 1 个元素；省略时默认 `['验收', '付款', '违约', '税率']`。
- 传空数组 `[]` 抛 `RangeError`，不静默回退到默认值，避免调用方误以为统计了自己给的关键词。
- 元素非字符串抛 `TypeError`，空字符串抛 `RangeError`。
- 列表内重复的关键词各占一条结果，便于调用方保持自己的展示顺序。

### 匹配口径

- 字面量匹配，不区分大小写：`Payment`、`PAYMENT`、`payment` 都会被关键词 `payment` 命中。
- 关键词中的正则元字符按字面量转义：关键词 `A+B` 只匹配文本里的 `A+B`，不匹配 `AAB`；关键词 `.` 只匹配真正的句点。
- 位置以 Unicode 码点计算，因此 `付款` 在 `😀付款` 中的 `firstIndex` 为 `1`。
- 空文本 `""` 返回 `textLength: 0`、`totalHits: 0`，每个关键词 `count: 0`、`firstIndex: -1`、`snippet: ""`。

已知限制：`snippet` 只截取首次命中，其余命中次数仅反映在 `count` 中；不做词形还原、同义词扩展或分词（`违约金` 不含 `违约` 之外的语义判断，`付款条件` 会命中 `付款`）；不解析条款结构，不能区分“条款正文”“目录”“引用”中的出现；大小写折叠依赖 JavaScript 正则的 Unicode 简化折叠，不覆盖 `ß` / `SS` 这类完整折叠；`text` 非字符串时抛 `TypeError`，不做隐式转换。

**专业提示**：命中次数只是复核线索。命中不等于条款完整、有效或已履行；未命中也不等于条款缺失（可能换了措辞，如“质量保证”“质量保证金”）。结论需回到文本上下文与原始文件。

## 权限与副作用

无文件读写、无网络、无子进程、无系统权限；只接收字符串与字符串数组并返回统计结果。
