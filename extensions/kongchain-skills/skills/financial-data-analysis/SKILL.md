# 财务数据分析

## 适用场景

- 两张或多张表格的金额/记录比对；
- 财务数据质量检查（重复、缺失、格式、期间）；
- 总额与明细、账表勾稽；
- 异常筛选、抽样、分层分析；
- 编写可复现的 Python/脚本程序。

## 分析步骤

1. **明确口径**：数据期间、主体、币种、金额字段（含税/不含税）、记录粒度、唯一键。
2. **数据画像**：行数、列名、类型、空值、重复、金额范围、日期范围、编码一致性。
3. **清洗规则**：去空格、统一大小写/编码、日期格式、金额精度；记录每一步，不静默丢弃。
4. **勾稽与比对**：
   - 总额 vs 明细合计；
   - 左连接/右连接/全连接找差异；
   - 多键匹配（单号+金额+日期+供应商）；
   - 容差与四舍五入规则显式化。
5. **异常筛查**：重复键、金额为负/零、期末集中、阈值附近、分布尾部；异常只作为线索。
6. **抽样**：随机/系统/分层；记录随机种子与样本清单。
7. **结果与限制**：差异清单、数量/金额、未匹配项、口径限制、需要补充的数据。

## 编写比较程序的要求

- 输入路径、编码、列名参数化；
- 显式处理缺失值与类型转换；
- 金额用 `Decimal` 或分为单位的整数，避免浮点误差；
- 输出差异明细 CSV/表格 + 汇总统计 + 运行日志；
- 使用固定随机种子；
- 不把“程序跑通”当作“数据正确”；要给出核对总数与抽样复核。

## 常用检查清单

- [ ] 唯一键是否唯一
- [ ] 金额合计是否等于明细合计
- [ ] 借贷/收付方向是否正确
- [ ] 日期是否在期间内
- [ ] 重复记录（完全相同/业务键相同）
- [ ] 未匹配记录（左/右独有）
- [ ] 容差内差异是否可解释
- [ ] 输出是否可复现

## 表述

- 区分“数据差异事实”和“差异原因推断”；
- 精确计算用程序工具完成并保留脚本；
- 对无法判断的差异说明缺什么信息。
