# 采购与付款分析

## 适用场景

- 解释采购付款环节常见内控风险与控制点；
- 分析采购合同、订单、验收单、发票、付款记录之间的一致性；
- 设计检查程序、抽样或异常筛查思路；
- 讨论供应商管理与付款账户变更风险。

本技能提供分析框架，不规定用户必须按某个固定审批流程执行；按任务实际范围裁剪。

## 业务阶段与典型风险

| 阶段 | 典型风险 | 可能的控制/证据 |
|---|---|---|
| 请购 | 无预算、重复请购、需求不实 | 预算控制、请购审批、需求合理性复核 |
| 供应商选择 | 虚假/关联供应商、围标、资质过期 | 准入审核、比价/招标、关联方筛查、资质复核 |
| 订单/合同 | 价格不公允、条款不利、超授权、拆分规避审批 | 授权矩阵、合同评审、价格比对、订单与合同一致 |
| 验收 | 未验收付款、数量/质量不符、验收人无权限 | 验收单、验收标准、职责分离、实物/服务确认 |
| 发票 | 虚假发票、重复报销、税率/金额错误、票货不符 | 发票查验、三单匹配、税务信息核对 |
| 付款 | 重复付款、超合同付款、账户被篡改、提前付款 | 付款审批、账户白名单/变更复核、付款计划、银行回单 |
| 记录/归档 | 凭证缺失、期间错配、附件不全 | 凭证附件完整性检查、截止性测试、归档复核 |

## 关键检查思路

1. **三单/四单匹配**：请购/订单/合同—验收—发票—付款的主体、金额、数量、日期、币种、税率、账户是否一致。
2. **重复与拆分**：相同发票号/合同号/金额/供应商组合；同日多笔略低于审批阈值的付款；连续编号缺口。
3. **供应商异常**：新设供应商大额交易、账户与名称不一致、收款账户频繁变更、注册信息异常、关联方未披露。
4. **时间与截止**：验收日期晚于付款、发票日期跨期、期末突击付款、长期挂账。
5. **价格与数量**：订单单价与合同/市场价差异、累计付款超合同、验收数量与发票数量差异。
6. **职责分离**：请购、审批、采购、验收、付款、记账是否由不相容岗位兼任。

## 分析模拟资料时

- 先列资料清单与缺口，再提取字段；不要假设缺失文件存在。
- 逐项标注“已核对/未核对/无法核对”，给出证据位置（文件名、页码、字段）。
- 异常只写“需进一步核实”，并列出核实所需资料。
- 金额、税额、比例、汇总用程序工具计算并保留过程。

## 输出建议

- 风险解释：按阶段列“风险—控制—证据—限制”；
- 资料分析：先给关键字段表，再给一致性与异常清单，最后给限制与下一步；
- 不把“发现异常”写成“存在舞弊”。
