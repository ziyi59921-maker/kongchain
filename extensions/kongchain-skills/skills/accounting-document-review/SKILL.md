# 会计与业务单据审阅

## 适用场景

- 用户提供（或要求分析）采购合同、发票、验收单、付款申请/回单等资料；
- 需要提取关键条款、建立字段表、检查单据间一致性；
- 需要说明资料缺口和核对限制。

仅分析实际可见的内容；未提供的文件、页码、签章不得假设存在。

## 合同关键条款清单

- 合同主体：名称、统一社会信用代码/注册信息、地址、联系人；
- 标的与范围：货物/服务名称、规格、数量、质量标准；
- 价格与税务：单价、总价、币种、含税/不含税、税率、发票类型；
- 付款条件：账期、分期节点、预付比例、尾款/质保金、付款账户；
- 交付与验收：交付时间、地点、验收标准、验收期限、风险转移；
- 违约与争议：违约责任、赔偿、解除条件、争议解决；
- 生效与签署：生效条件、签署日期、签章、授权代表；
- 其他：保密、知识产权、合规/廉洁条款、变更机制。

## 审阅步骤

1. 列资料清单：文件名、类型、页数/版本、日期；说明哪些是用户提供、哪些缺失。
2. 提取字段，保留原文位置（页码/条款号）。
3. 做一致性检查：主体、金额、数量、税率、日期、账户、签章。
4. 识别异常条款或缺口：空白条款、前后矛盾、付款条件与验收脱节、账户与主体不一致、签章缺失。
5. 给出限制：资料不完整、版本不明、无法验真、无法取得外部证据。
6. 用程序工具核算金额/税额/分期比例。

## 表述要求

- 引用条款时写“第 X 条/第 X 页”，不要编造条款号。
- 区分“合同约定”“资料显示”“我方推断”。
- 发现异常时说明可能原因和核实方法，不直接定性违规或舞弊。
