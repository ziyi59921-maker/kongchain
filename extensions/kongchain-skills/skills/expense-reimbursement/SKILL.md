# 费用报销

## 适用场景

- 解释费用报销环节的风险、控制点与证据；
- 检查报销单、发票、审批、支付记录的一致性；
- 设计重复报销、超标准、跨期、拆分报销的筛查。

## 风险与控制

| 阶段 | 风险 | 控制/证据 |
|---|---|---|
| 事前 | 无预算、超标准、私人消费混入 | 费用政策、预算、事前审批 |
| 单据 | 虚假/重复发票、抬头错误、附件不全 | 发票查验、原件、行程/会议/招待证明 |
| 审批 | 越权审批、自己审自己、拆分规避 | 授权矩阵、职责分离、阈值 |
| 支付 | 重复付款、收款人与报销人不一致 | 付款记录、账户核对、批量去重 |
| 入账 | 科目错误、跨期、资本化与费用化混淆 | 凭证、期间、科目政策 |

## 检查要点

- 同一发票号/金额/日期/报销人重复；
- 同日多笔略低于审批阈值；
- 发票抬头、税号、日期、金额与报销单不一致；
- 无审批、审批人无权限、审批时间晚于支付；
- 费用与业务目的不匹配（如个人消费、家属费用）；
- 期末集中报销、跨期入账。

## 证据与限制

- 保留原始发票、报销单、审批记录、支付回单、业务证明；
- 异常只是线索，不直接认定为违规或舞弊；
- 未取得原始单据时明确写“未核对”，不得编造。
