# 资产管理

## 适用场景

- 固定资产、在建工程、无形资产、存货的内控风险；
- 资产取得、验收、入账、折旧/摊销、盘点、处置；
- 账实核对、权属证明、资本化与费用化判断。

## 风险与控制

| 环节 | 风险 | 控制/证据 |
|---|---|---|
| 取得 | 未授权采购、资本化错误、关联交易 | 预算/审批、合同、发票、验收 |
| 入账 | 价值/期间错误、分类错误 | 入账凭证、折旧政策、资产卡片 |
| 保管 | 丢失、挪用、账实不符 | 标签、责任人、存放地点、盘点 |
| 折旧/减值 | 政策不一致、减值不及时 | 折旧表、减值测试、复核 |
| 处置 | 未授权处置、收入未入账 | 处置审批、评估/比价、收款记录 |
| 盘点 | 盘点范围不全、差异未处理 | 盘点计划、盘点表、差异分析 |

## 检查要点

- 资产卡片与总账、明细账一致；
- 实物存在、标签、存放地点、责任人；
- 折旧年限/残值/方法一致性；
- 闲置、报废、盘亏资产是否及时处理；
- 处置价格与评估/市场价对比。

## 限制

- 盘点需要现场证据；仅凭台账不能证明存在；
- 权属需产权证/合同/付款证据；
- 差异原因需进一步核实，不能直接定性。
