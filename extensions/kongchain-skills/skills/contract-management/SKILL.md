# 合同管理

## 适用场景

- 合同评审与条款提取（可只关注验收、付款、违约等指定条款）；
- 合同授权、签署、用印、归档；
- 履约、验收、付款、变更、终止；
- 合同与订单、发票、验收、付款的一致性。

## 关键条款

- 主体与授权：名称、信用代码、签署人授权；
- 标的与价格：范围、数量、单价、总价、税率、发票类型；
- 交付与验收：时间、地点、标准、期限、风险转移；
- 付款：预付款、进度款、质保金、账户、凭票付款；
- 变更/解除/违约/争议解决；
- 保密、知识产权、廉洁合规。

## 风险与控制

| 风险 | 控制/证据 |
|---|---|
| 未授权签署、越权 | 授权矩阵、用印审批、授权书 |
| 条款不利/空白条款 | 合同评审、模板、法务/财务会签 |
| 履约与验收脱节 | 验收单、交付记录、里程碑 |
| 付款与合同不符 | 付款审批、合同/发票/验收匹配 |
| 变更无书面记录 | 变更审批、补充协议 |
| 归档缺失 | 合同台账、版本、附件清单 |

## 限制

- 合同文本分析只对提供的版本有效；缺失附件/签章需说明；
- 异常条款是谈判/核实线索，不直接认定无效或舞弊。
